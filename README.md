Tread (tread.io / tread.ai) is the operating system for bulk materials hauling — a dispatch and logistics TMS for construction-materials producers, contractors, and haulers. The Tread Horizon platform unifies order management, truck dispatching, route and driver tracking, e-ticketing, driver timesheets, settlements, and billing across web and a mobile driver/foreman app. Its public Horizon API V1 is a REST/JSON API (OpenAPI 3.0.3, 562 paths, 732 operations) covering Projects, Orders, Jobs, Loads, Tickets, Sites, Materials, Equipment, Settlements, and Invoices, with HMAC-signed webhooks, bearer-JWT / OAuth2 client-credentials auth, cursor pagination, and integrations to QuickBooks, Sage, Vista, Foundation, Spectrum, HCSS, Samsara/Geotab telematics, and Agave.

**Areas:** Company · Construction · Logistics · Transportation Management · Dispatch · Fleet Management · Bulk Materials · Trucking · Webhook

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for tread.io: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
